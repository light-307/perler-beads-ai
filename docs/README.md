## 命名约定

- 文档文件名以中文为主，目录按用途划分：`部署/`、`功能/`、`参考/`、`规划/`、`images/`。
- 文档内引用源码时使用**相对仓库根的相对路径**（如 `../../src/app/page.tsx`），不要写入本机绝对路径。
